// The Story Behind LogiMap

🎯

The Problem

Food aid distribution in Lhokseumawe involved thousands of recipients across multiple districts. Manual tracking led to data inconsistencies, delayed reports, and difficulty in verifying real-time stock levels.

💡

The Solution

LogiMap integrates spatial mapping with relational database management. Each distribution point is geo-tagged, every transaction is logged in MySQL, and the dashboard visualizes everything in real-time.

⚙️

Tech Architecture

Frontend built with vanilla JS + Leaflet.js for maps. Chart.js for analytics. Backend powered by MySQL with normalized tables for recipients, stock, and transactions. Designed for scalability.

📈

The Impact

Reduced reporting time by 70%. Eliminated data duplication errors. Enabled field officers to verify recipient data on-the-spot using mobile devices. 100% audit trail for every kg of rice distributed.
